# AutoBuy-MofidBroker

ربات خرید خودکار برای بورس مفید (پلتفرم EasyTrader).  
منتظر ساعت دقیض بورس می‌شود، سپس دکمه خرید را تکرار می‌زند تا تأیید شد.

---

## ویژگی‌ها

- **تایمینگ دقیق** — منتطر ساعت سرور بورس (نه ساعت سیستم)
- **پشتیبانی از چندین نمونه** — اجرای هم‌زمان چندین نمونه با پروفایل‌های جداگانه کروم
- **تأیید سفارش** — پس از خرید موفق، به تب سفارش‌ها می‌رود و سفارش را چک می‌کند
- **یافتن دکمه قوی** — چندین شناسه fallback برای یافتن دکمه خرید
- **دریافت پیام بورس** — اسکن DOM برای پیام‌های موفقیت/خطا به فارسی و انگلیسی
- **پیکربندی محیطی** — اعتبار و تنظیمات از طریق `.env` یا متغیرهای محیطی
- **بستن منظم** — Ctrl+C مرورگر را به‌طور کامل می‌بندد

## نصب

```bash
pip install -r requirements.txt
```

### درایور کروم

این پروژه از **درایور کروم لوکال** استفاده می‌کند (برای محیط‌های بدون دسترسی اینترنت).  
مسیر درایور را در فایل `.env` تنظیم کنید:

```
CHROMEDRIVER_PATH=C:\Users\Mahdi\.cache\selenium\chromedriver\win64\148.0.7778.97\chromedriver.exe
```

اگر درایور روی PATH سیستم باشد، این گزینه را خالی بگذارید.

## پیکربندی (`config.py`)

| متغیر | مقدار پیش‌فرض | توضیح |
|--------|---------------|-------|
| `MOFID_USER` | (اجباری) | نام کاربری بورسی |
| `MOFID_PASS` | (اجباری) | رمز عبور بورسی |
| `DEFAULT_BUY_TIME` | `08:44:58` | ساعت هدف برای خرید (HH:MM:SS) |
| `SYMBOL` | `""` | نماد برای شناسایی در لاگ |
| `BROKER_URL` | `https://d.easytrader.ir/` | آدرس لاگین |
| `VERIFY_ORDER` | `true` | تأیید سفارش در تب سفارش‌ها |
| `CHROME_USER_DATA_DIR` | `""` | پوشه پروفایل کروم (برای چند نمونه) |
| `HEADLESS` | `false` | اجرا بدون رابط گرافیکی |
| `INSTANCE_ID` | `""` | شناسه نمونه برای لاگ‌گیری |

فایل `.env` را از قالب ساختید:

```bash
copy .env.example .env
# فایل .env را ویرایش و اعتبار را وارد کنید
```

## استفاده

### نمونه تکی (با زمان پیش‌فرض)

```bash
python main.py
```
با زمان `DEFAULT_BUY_TIME` (۰۸:۴۴:۵۸) کار می‌کند.

### تعیین زمان

```bash
python main.py --time 09:00:00
```

### چند نمونه همزمان (هر ترمینال یک نماد)

ترمینال ۱:
```bash
INSTANCE_ID=folad CHROME_USER_DATA_DIR=C:\chrome-folad python main.py
```

ترمینال ۲:
```bash
INSTANCE_ID=kalan CHROME_USER_DATA_DIR=C:\chrome-kalan python main.py
```

هر نمونه:
- پروفایل کروم جدا دارد (بدون تداخل کوکی/لاگین)
- لاگ‌ها شامل `[instance: folad]` یا `[instance: kalan]` است

---

## جریان کاری

۱. **لاگین** — خودکار با Selenium  
۲. **آماده‌سازی دستی** — کاربر نماد/قیمت/تعداد را می‌گذارد (اسکریپت منتظر Enter)  
۳. **انتظار به ساعت** — منتطر ساعت بورس ≥ زمان هدف  
۴. **خرید خودکار** — تا ۲۵ کلیک روی دکمه خرید، با فاصله ۱۵۰ میلی‌ثانیه  
۵. **تأیید** — در صورت فعال بودن، سفارش در تب سفارش‌ها چک می‌شود

2026-06-10 12:20:17 [INFO] main: AutoBuy-MofidBroker starting (instance: folad) - Symbol: فولاد

## عیب‌یابی

| مشکل | راه‌حل |
|------|--------|
| «لاگین ناموفق» | اعتبار در `.env` را چک کنید |
| «دکمه خرید پیدا نشد» | مطمئن شوید صفحه نماد لود شده و فرم قابل دیدن است |
| «ساعت بورس پیدا نشد» | صبر کنید تا صفحه کاملاً لود شود؛ اتصال اینترنت را چک کنید |
| کروم بعد از Ctrl+C می‌ماند | مطمئن شوید `--user-data-dir` توسط پروسه دیگر قفل نشده |
| «سفارش پس از تمامی تلاش‌ها پذیرفته نشد» | بررسی دستی؛ بورس ممکن است به دلیل قیمت/تعداد رد کرده باشد |
