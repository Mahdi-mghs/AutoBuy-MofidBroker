# AutoBuy-MofidBroker

ربات خرید خودکار برای کارگزاری مفید (پلتفرم EasyTrader)، بازنویسی‌شده با **Playwright**.
وارد می‌شود، **سفارش را خودش آماده می‌کند** (نماد، قیمت، تعداد)، منتظر ساعت دقیق بورس
می‌ماند و سپس دکمه خرید را تا تأیید شدن تکرار می‌کند.

راهنمای انگلیسی: [README.md](README.md)

---

## ویژگی‌ها

- **آماده‌سازی کاملاً خودکار** — رفتن به نماد، باز کردن برگه خرید، پر کردن قیمت و تعداد؛ دیگر خبری از `Press ENTER` دستی نیست
- **حالت‌های قیمت** — `ceiling` (سقف قیمت، پیش‌فرض)، `reference` (قیمت پایانی) یا `fixed` (قیمت ثابت)
- **بازخوانی ایمنی** — نماد برگه بررسی می‌شود و تعداد/قیمت بعد از پر شدن دوباره خوانده می‌شوند؛ در صورت مغایرت ربات خرید نمی‌کند
- **تایمینگ دقیق** — منتظر ساعت سرور بورس (نه ساعت سیستم)
- **پشتیبانی چند نمونه** — اجرای هم‌زمان چند نماد با پروفایل‌های جداگانه کروم
- **تأیید سفارش** — بعد از خرید موفق، لیست سفارش‌ها بررسی می‌شود
- **یافتن قوی دکمه خرید** — سلکتور اصلی `data-cy` به همراه چند fallback و کلیک با تلاش مجدد
- **تشخیص پیام بورس** — خواندن toast و اسکن DOM برای پیام فارسی/انگلیسی؛ کلمات خطا **قبل** از کلمات موفقیت بررسی می‌شوند
- **حالت دستی** — سوییچ `--manual` همان رفتار قبلی (آماده‌سازی توسط خودتان) را برمی‌گرداند
- **پیکربندی محیطی** — اعتبار و تنظیمات از `.env` یا متغیرهای محیطی
- **بستن منظم** — Ctrl+C مرورگر را کامل می‌بندد
- **بدون ChromeDriver** — Playwright با کروم نصب‌شده کار می‌کند؛ دیگر نیازی به هم‌نسخه کردن درایور نیست

## نصب

```bash
pip install -r requirements.txt
```

Playwright از **گوگل کروم نصب‌شده** استفاده می‌کند (`channel="chrome"`)، پس دانلود مرورگر لازم نیست.
اگر کروم نصب نیست:

```bash
playwright install chromium
```
و در `driver.py` مقدار `channel="chrome"` را به `channel="chromium"` تغییر دهید.

فایل `.env` را از قالب بسازید:

```bash
copy .env.example .env
# فایل .env را ویرایش و اعتبار را وارد کنید
```

## پیکربندی

| متغیر | مقدار پیش‌فرض | توضیح |
|--------|---------------|-------|
| `MOFID_USER` | (اجباری) | نام کاربری بورسی |
| `MOFID_PASS` | (اجباری) | رمز عبور بورسی |
| `SYMBOL` | `""` | نماد مورد معامله، مثلاً `فولاد` (در حالت خودکار اجباری) |
| `QUANTITY` | `0` | تعداد سهام (در حالت خودکار باید بزرگ‌تر از صفر باشد) |
| `PRICE_MODE` | `ceiling` | `ceiling` (سقف قیمت) \| `reference` (قیمت پایانی) \| `fixed` |
| `PRICE` | `0` | قیمت ثابت — فقط در `PRICE_MODE=fixed` |
| `DEFAULT_BUY_TIME` | `08:44:58` | ساعت هدف خرید (HH:MM:SS) |
| `BROKER_URL` | `https://d.easytrader.ir/` | آدرس لاگین |
| `VERIFY_ORDER` | `true` | تأیید سفارش در لیست سفارش‌ها |
| `CHROME_USER_DATA_DIR` | `""` | پوشه پروفایل کروم (برای چند نمونه) |
| `HEADLESS` | `false` | اجرا بدون رابط گرافیکی |
| `INSTANCE_ID` | `""` | شناسه نمونه برای لاگ‌گیری |

فهرست کامل (تایم‌اوت‌ها، تعداد تلاش‌ها، فایل لاگ) در [`.env.example`](.env.example).

## استفاده

### نمونه تکی (آماده‌سازی خودکار)

```bash
python main.py --time 08:44:58 --symbol فولاد
```

`--symbol` روی `SYMBOL` اولویت دارد؛ ساعت هدف به‌صورت پیش‌فرض از `DEFAULT_BUY_TIME` خوانده می‌شود.

### بدون تأیید سفارش

```bash
python main.py --time 09:00:00 --no-verify
```

### حالت دستی (رفتار قدیمی)

```bash
python main.py --manual
```

ربات لاگین می‌کند و سپس متوقف می‌شود تا شما خودتان برگه خرید را پر کنید.

### چند نمونه هم‌زمان (هر ترمینال یک نماد)

ترمینال ۱:
```bash
INSTANCE_ID=folad CHROME_USER_DATA_DIR=C:\chrome-folad SYMBOL=فولاد QUANTITY=10 python main.py
```

ترمینال ۲:
```bash
INSTANCE_ID=kalan CHROME_USER_DATA_DIR=C:\chrome-kalan SYMBOL=کالن QUANTITY=5 python main.py
```

هر نمونه پروفایل کروم جدا دارد (بدون تداخل کوکی/لاگین) و لاگ‌ها با شناسه نمونه مشخص می‌شوند.

## جریان کاری

۱. **لاگین** — خودکار با Playwright
۲. **آماده‌سازی** — خودکار: جستجوی نماد → انتخاب نتیجه دقیق → برگه خرید → تعداد → قیمت بر اساس `PRICE_MODE` → بازخوانی و بررسی
۳. **انتظار ساعت** — تا رسیدن ساعت بورس به زمان هدف
۴. **خرید خودکار** — تا ۲۵ کلیک با فاصله ۱۰۰ میلی‌ثانیه تا تأیید بورس
۵. **تأیید** — بررسی لیست سفارش‌ها

اگر در هنگام آماده‌سازی زمان هدف گذشته باشد، ربات **بدون خرید** خارج می‌شود.

## تست

تست‌های سریع بدون مرورگر (منطق زمان‌بندی، تشخیص پیام، سیم‌کشی اصلی):

```bash
pip install -r requirements-dev.txt
python -m pytest tests -q
```

تست دودی با مرورگر واقعی — تمام مسیر **به‌جز کلیک نهایی خرید**، همراه با اسکرین‌شات
هر مرحله در `artifacts/`:

```bash
python smoke_test.py --symbol فولاد
```

این تست نماد/تعداد/قیمت برگه و دیده‌شدن دکمه خرید را بررسی می‌کند و بدون ارسال سفارش
خارج می‌شود. جزئیات: [docs/adr/003](docs/adr/003-real-browser-testing-without-submitting.md)

## عیب‌یابی

| مشکل | راه‌حل |
|------|-------|
| «لاگین ناموفق» | اعتبار در `.env` را چک کنید |
| «نماد/تعداد تنظیم نشده» | `SYMBOL` و `QUANTITY` (> ۰) را تنظیم کنید یا از `--manual` استفاده کنید |
| «Order ticket opened for X, expected Y» | انتخاب نماد دو بار اشتباه شد؛ املای نماد را چک کنید — ربات به‌جای معامله نماد اشتباه متوقف می‌شود |
| «Layout overlay still active» | یک مودال/پنل صفحه را قفل کرده؛ دوباره اجرا کنید (ربات Escape و کلیک روی backdrop را خودش امتحان می‌کند) |
| «ساعت بورس پیدا نشد» | صبر کنید تا صفحه کامل لود شود؛ اتصال اینترنت را چک کنید |
| «Target time already passed» | زودتر شروع کنید یا `--time` دیرتری بدهید |
| «سفارش پس از تمام تلاش‌ها پذیرفته نشد» | بررسی دستی؛ ممکن است بورس به دلیل قیمت/تعداد رد کرده باشد |
| کروم بعد از Ctrl+C می‌ماند | مطمئن شوید `--user-data-dir` توسط پروسه دیگری قفل نشده باشد |
